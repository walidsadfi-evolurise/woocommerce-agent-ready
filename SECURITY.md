# Security

This tool only sends public, unauthenticated, read-only requests to the store
you point it at (plus JSON-RPC `initialize` handshakes to detect MCP endpoints).
It stores nothing and sends nothing to third parties.

If you find a vulnerability in the tool itself, email walid.sadfi@evolurise.com
with details. Please do not open a public issue for security reports. You will
get an answer within 5 working days.
